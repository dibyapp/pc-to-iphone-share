# First 30 days: an organic 100-star experiment

Owner: [dibyapp](https://github.com/dibyapp). Start the 30-day clock on the repository's first public publication date. Target: 100 voluntary, organic GitHub stars. This is a stretch target; neither SEO nor this plan guarantees it. Stars should reflect usefulness, not purchased traffic, reciprocal starring, giveaways, bots, or mass unsolicited promotion.

## The funnel to improve

Useful guide or demo → relevant repository visitor → successful setup and download → optional star or contribution.

For planning only: 2,000 relevant unique visitors at an assumed 5% visitor-to-star rate would produce 100 stars. At 2%, it would take 5,000 visitors; at 10%, 1,000. These are hypothetical conversion scenarios, not observed rates or traffic predictions. Search indexing and ranking can take time, so first-month discovery also needs useful community participation and referrals.

Check each community's current rules before a later submission; do not repost the same pitch repeatedly.

## Draft launch copy

**Show HN title:** Show HN: PC to iPhone Share – download a computer folder on your phone over Wi-Fi

**Short introduction:** I built PC to iPhone Share for a narrow task: browsing and downloading one computer folder from an iPhone or Android browser on the local network. It is MIT licensed, read-only, and uses password-protected HTTPS. Portable builds cover Windows, macOS, and Linux x64/ARM64. The first release is an unsigned alpha, and phone certificate pairing is manual. I would value feedback on setup and platform compatibility. Source and downloads: https://github.com/dibyapp/pc-to-iphone-share

**Technical article outline:** The folder-download problem; why an explicit local server fits; selected-interface binding; TLS trust and first-time pairing; `os.Root` and linked-path rejection; same-origin cookies; range downloads; remaining limitations; reproducible build/test instructions.

**Optional README invitation:** If PC to iPhone Share solves your folder-download problem, a star helps other people find it. Bug reports and verified platform results are equally useful.
