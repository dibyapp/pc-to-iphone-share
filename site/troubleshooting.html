Connection help,
without guesswork.

Check the exact phone address, selected interface, certificate trust, and receiving-device storage before changing settings.

The page cannot be reached

Use the separately displayed phone URL including https:// and the app port (9443 by default). The dashboard is computer-only and cannot be used from the phone. Both devices need a reachable private network; guest Wi-Fi client isolation can block them. Check that the terminal is still open, the computer is awake, and the chosen interface is the intended LAN interface.

The certificate could not be verified

Trust is per receiving device. Verify the fingerprint using the local computer dashboard through a trusted channel, install only that computer's public CA/profile, and enable full trust on iPhone/iPad. Trusting the certificate on Windows does not trust it on an iPhone. The app does not turn off certificate verification. See the certificate guide for supported manual steps.

Safari says cross-site requests are blocked

Open the exact phone URL directly in a fresh Safari tab and sign in there. Use one scheme, hostname/address, and port for the session. Do not embed the page in another site or reuse a dashboard URL. Protected APIs intentionally reject cross-site requests; disabling Safari privacy settings is not the documented fix.

The executable will not start

Choose the correct CPU/OS archive and extract it before running. On Linux, check execute permission and noexec mounts. Unsigned Windows/macOS binaries may be blocked by OS protections; use an inspected source build until signing is available. Old or unsupported operating systems and 32-bit hosts are outside the packaged targets.

A download stops or a file is missing

Keep the computer awake and the app running. Check phone storage and the browser download manager. Resume depends on the client despite HTTP range support. Search filters loaded entries: use Load more files for additional pages. Dot paths, symlinks/junctions, and invalid names are intentionally excluded; directories over 10,000 entries should be split.

Still stuck?

Report the app version, OS/CPU, sanitized error message, and synthetic reproduction steps. Never post private addresses, usernames, paths, filenames, passwords, dashboard URLs/tokens, config, keys, or certificate fingerprints in a public issue.
