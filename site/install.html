2. Extract and start

Keep the portable app outside the folder you will share. Windows: run Start-PC-to-iPhone-Share.cmd. macOS: run ./pc-to-iphone-share in Terminal. Ubuntu/Linux: extract the TAR.GZ and run ./pc-to-iphone-share in a terminal. No Go, Node, Python, admin installation, or package-manager command is needed to run a binary. Binaries are unsigned and unnotarized; the app does not bypass OS protections.

3. Choose your folder and network

Select one dedicated folder and the actual private interface reachable by your phone. Keep the computer awake. The app leaves your firewall, router, certificate trust, and services under your control.

4. Pair, sign in, download

Open the computer dashboard from the console, keep that management URL private, and use the separate phone URL. Verify the local CA fingerprint through a trusted channel, install only your own public certificate, and explicitly enable trust on iPhone/iPad. Enter the generated password and tap a filename.

Device certificate pairing · Connection help

Prefer an inspected source build?

Clone the repository, install Go 1.26, run go test ./... and go vet ./..., then build with -trimpath -buildvcs=false. The optional Python source-repository installer verifies the pinned release checksum and never launches or overwrites an existing app.

Windows x64 and Ubuntu 24.04 under WSL 2 passed local runtime checks. Other architecture and physical-device results are documented openly. iOS and Android are receiving clients; there is no mobile server package or automatic discovery.
